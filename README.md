# Money — ローカル家計グラフ

マネーフォワード形式の月別CSVから、カテゴリ（大項目）ごとの収支を比較するWebアプリです。Python / Flaskで画面を表示し、PillowでPNGを生成します。データベースは使用しません。

## 起動

Python 3.12以上と[uv](https://docs.astral.sh/uv/)を使用します。

```sh
cd /Users/tttol/Documents/workspace/money
uv sync --locked
uv run --offline python app.py
```

ブラウザで **http://127.0.0.1:8765** を開きます。終了はターミナルで `Ctrl+C` です。ポートが使用中なら `uv run --offline python app.py --port 8766` で変更できます。

初回の依存ライブラリ取得にはインターネット接続が必要です。取得後の起動・CSV集計・PNG出力では、外部通信を行いません。画像・フォント・画面用資材を外部サイトから読み込む処理もありません。サーバーは `127.0.0.1` にのみバインドします。

## 使い方

1. `money_forward_csv/` に月別のCSVを置きます。すでに配置した2026年9月・10月のCSVをそのまま使用できます。
2. 初期表示では直近の異なる2か月を自動で選びます。「比較元の月」「比較先の月」を変更して「比較する」を押すと、任意の月を比較できます。
3. 「支出」「収入」タブで表示を切り替えます。
   各カテゴリのグラフをクリックすると、2か月分の明細をモーダルで確認できます。月ごとの合計・件数と、日付・内容・金額・中項目・メモを箇条書きで表示します。グラフと同じ集計条件を使用し、対象明細がない月はその旨を表示します。
   「内容」が完全に一致する明細は、2か月分を同じ行の左右に配置します。同名の明細が月内に複数ある場合は合計・件数と個々の明細をまとめて表示し、片方の月にしかない場合は反対側に「この月の明細なし」と表示します。差額の大きい名前から順に並べます。狭い画面でも2か月分は横並びです。
   モーダルは閉じるボタン・背景のクリック・Escキーで閉じられます。キーボードではグラフのボタンにTabキーで移動し、EnterまたはSpaceキーで開けます。
4. 「グラフをPNGで保存」で、表示中の区分の全カテゴリを1枚の画像に保存できます。PNGはメモリ上で生成され、サーバー側に画像ファイルは残りません。
5. 「CSVを追加」からも1か月分のCSVを追加できます。検証後、月とファイル内容のハッシュを使う名前で `money_forward_csv/` に保存します。元のCSVは上書きしません。同じ内容の追加は重複保存しません。

同じ月のCSVが複数ある場合も自動合算しません。プルダウンのファイル名を確認して、使用する1つを選んでください。

## 集計ルール

- 必須列：`計算対象`、`日付`、`金額（円）`、`大項目`、`振替`。
- UTF-8（BOMあり・なし）、Shift_JIS / CP932に対応。1ファイル10MB以下、1か月分の明細を想定しています。
- `計算対象=1` かつ `振替=0` の行だけを集計します。
- 金額がマイナスの行を支出、0以上の行を収入とし、カテゴリ別に集計します。支出の表示額は絶対値です。返金などのプラス金額も収入側に表示します。
- 縦軸の数値は千円単位。カテゴリごとに縮尺を変え、同カテゴリの2か月は同じ縮尺を使用します。
- 比較先の増加はオレンジ、減少は青、同額はグレーで表示します。色は金額の増減を示し、良し悪しは評価しません。
- 片方の月にカテゴリの明細がない場合は0円。比較元が0円のときは増減率を計算しません。
- 重複した明細ID、不正な金額・日付、複数月が混在するCSVはエラーにします。
- 1ファイルのカテゴリ数は収支区分を合わせて60個までです。
- 月末までのデータが揃っているかは判定しません。使用CSVの最終明細日・集計対象件数・除外件数を確認できます。

CSVと生成したPNGには家計情報が含まれます。`.gitignore` でCSVフォルダとPNGを除外しています。

## テスト

```sh
uv run --offline python -m pytest
```

テストは一時フォルダ内のサンプルCSVを使用し、個人の家計CSVを変更しません。

## 構成

- `money/domain.py`：月別集計値・カテゴリ比較・増減率・軸の計算
- `money/csv_source.py`：CSVの文字コード判定・検証・集計
- `money/repository.py`：CSVのローカル保存・読込
- `money/charts.py`：PNG描画
- `money/web.py`：Flaskの画面・追加・ダウンロード処理
- `money/templates/`、`money/static/`：サーバー描画のHTML・CSS

PNGの日本語描画はmacOSのヒラギノを使用します。LinuxではNoto Sans CJK、WindowsではMeiryoにも対応しています。
